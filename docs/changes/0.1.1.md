- `--check-upstream`: for floating official php tags such as `php:8.3-fpm`, asks Docker Hub which PHP the tag's current image sets and says "upstream rebuilt with 8.3.x, rebuild and redeploy now" or "not rebuilt yet, check again later". Findings stay in CHECK MANUALLY, because your own image is old until you rebuild it. Anonymous and rate limited, so lookups are cached per run and a failure falls back to the normal message.
- `--repo owner/name`: scans one GitHub repo through the API without cloning. A token is optional for public repos.
- CI and dev findings now say they are lower exposure than a web-serving runtime, following php.net's advisory. Buckets don't change.
- JSON: `repo` (with `--repo`) and `findings[].upstream` (with `--check-upstream`) are new fields; `schemaVersion` stays 1.
